# Contributing

Thanks for helping make AI coding agents safer to use.

1. Open an issue before proposing a large change.
2. Keep rules narrow, explainable, and covered by tests.
3. Do not submit real secrets, client code, or private prompts.
4. Run `npm test` before opening a pull request.
5. Explain expected false positives and false negatives when adding a rule.
