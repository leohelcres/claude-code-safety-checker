# Claude Code Safety Checker

Una herramienta de línea de comandos, sin dependencias, que revisa archivos de instrucciones usados por agentes de programación con IA y señala riesgos frecuentes.

Los agentes no solo leen código: archivos como `CLAUDE.md`, `AGENTS.md` o la configuración dentro de `.claude/` pueden influir en las acciones que ejecutan. Este proyecto permite hacer una primera revisión local y transparente antes de dar acceso a un agente.

No sustituye una auditoría de seguridad ni envía tus archivos a ningún servicio.

Consulta la guía completa en [README.md](README.md).
